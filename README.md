# Joby George - Portfolio

Plain HTML, CSS and JavaScript. No build step, no installs.

## Before publishing
1. Replace `images/profile.jpg` with your photo (square, ~600x600).
2. Replace `images/photo1.jpg` to `photo6.jpg` with your macro and nature photos (4:3, ~800x600, compressed).
3. Replace `resume.pdf` with your real resume.
4. In `index.html`, update the email (`mailto:`), the LinkedIn URL, and each project's GitHub link.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push this folder to a GitHub repo (e.g. `Joby09050.github.io` or `portfolio`).
2. Settings > Pages > Deploy from branch > `main` / root.
3. Your site goes live at the URL GitHub shows.

## Notes
- GitHub stats and languages load from the public GitHub API.
- The streak card and contribution graph are loaded from third-party services; if they are down, they hide themselves.
